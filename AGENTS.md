# Portfolio Raisa Ochoa — Instrucciones para Codex

## 1. Descripción del proyecto

Portfolio personal e interactivo de Raisa Ochoa, enfocado en Desarrollo de Aplicaciones Web (DAW), Comunicación Audiovisual, diseño, música y producción audiovisual.

El objetivo es presentar proyectos, experiencia profesional, formación y habilidades mediante una experiencia visual original, accesible y profesional.

## 2. Concepto visual

La página principal representa una habitación minimalista, luminosa y acogedora.

Elementos principales:

- Presentación con nombre y profesión.
- Estantería de madera con carátulas de vinilos.
- Tocadiscos funcional sobre un mueble.
- Sofá verde oliva.
- Lámpara divertida e interactiva.
- Ventana con iluminación ambiental dinámica.
- Decoración discreta relacionada con música, fotografía y audiovisual.

Estética: diseño editorial contemporáneo, colores suaves, tonos naturales, madera, verde oliva y acentos pastel.

## 3. Interacción principal

Cada vinilo representa una sección del portfolio.

Al seleccionar una carátula:

1. Se anima su salida de la estantería.
2. Se extrae el disco de la funda.
3. Se coloca en el tocadiscos.
4. El brazo del tocadiscos se posiciona.
5. El vinilo comienza a girar.
6. Se muestra la información de la sección seleccionada.

Secciones: Sobre mí, Proyectos DAW, Audiovisual, Música, CV y Contacto.

## 4. Interacciones ambientales

- La lámpara podrá encenderse y apagarse mediante clic o teclado.
- El tocadiscos tendrá controles de reproducción.
- La iluminación exterior cambiará según la hora real.
- Las condiciones meteorológicas modificarán el ambiente de la habitación.
- Existirá un selector manual para cambiar el ambiente.
- Las animaciones respetarán `prefers-reduced-motion`.

La meteorología se obtendrá mediante una API y una ubicación autorizada por el visitante o seleccionada manualmente.

## 5. Tecnologías

- React y TypeScript.
- Vite como herramienta de desarrollo.
- CSS modular.
- GSAP para animaciones complejas.
- Three.js / React Three Fiber cuando aporte valor.
- Git para control de versiones.

## 6. Reglas de desarrollo

- Trabajar únicamente dentro de `portfolioRaisaJOchoa`.
- No acceder ni modificar Aula Circular, FRAMEWORK u otros proyectos personales.
- No ejecutar comandos destructivos sin autorización.
- No crear commits ni publicar cambios sin autorización.
- Priorizar código modular, mantenible y documentado.
- Mantener el diseño adaptable a diferentes pantallas.
- Utilizar HTML semántico y controles accesibles.
- Evitar dependencias innecesarias.
- No inventar experiencia profesional, formación ni proyectos.
- Explicar las decisiones técnicas importantes.

## 7. Metodología

Trabajar por fases:

1. Estructura y configuración inicial.
2. Maquetación de la habitación.
3. Estantería y carátulas interactivas.
4. Tocadiscos y animaciones.
5. Sistema de iluminación y meteorología.
6. Contenido profesional y proyectos.
7. Optimización, pruebas y publicación.

Antes de implementar una fase importante, presentar un plan breve y comprobar los archivos existentes.

## 8. Objetivo profesional

El portfolio debe demostrar habilidades de desarrollo frontend, diseño UI/UX, programación interactiva, integración de APIs y creatividad audiovisual, manteniendo una experiencia de usuario intuitiva.
